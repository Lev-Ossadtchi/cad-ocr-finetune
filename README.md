# Распознавание чертёжного шрифта: дообучение с замером

Готовые распознаватели читают чертежи плохо. Не потому, что чертежи сложные, а
потому, что шрифт им чужой: модели учились на фотографиях вывесок и сканах книг,
а на чертеже буквы вертикальные, равномерной толщины, со скруглёнными концами, и
рядом стоят записи, которых в обычном тексте не бывает — `DN/OD 160`,
`SDR17-63х3,8`, `i=0,005`.

Здесь проверено, что даёт дообучение под этот шрифт, и — что важнее — как оно
сначала сделало хуже.

## Цифры

Одна и та же модель (CRNN из EasyOCR, `cyrillic_g2`), одни и те же тестовые
подписи. Шаблоны записи, на которых меряли, в обучении не встречались вовсе.

| Модель | Символы | Строки целиком |
|---|---|---|
| Готовая, без дообучения | 86–89 % | 56–63 % |
| Дообученная целиком, 6 эпох | 83–84 % | 21–29 % |
| Свёртка заморожена, 2 эпохи | 91–93 % | 64–69 % |
| Свёртка заморожена + строчные буквы в обучении | **98,7–99,6 %** | **84–90 %** |

Разброс — это четыре уровня порчи картинки: от чистой векторной вырезки до
плохого скана. Подробная таблица по уровням — ниже.

## Почему дообучение сначала ухудшило результат

Первая же попытка — дообучить модель целиком на подписях с чертежа — уронила
долю верно прочитанных строк с 58 % до 24 %. Потеря на обучении при этом ушла
в ноль к четвёртой эпохе: модель выучила обучающие шаблоны наизусть и перестала
читать всё остальное.

Помогли две вещи, обе видны в ошибках, а не в догадках.

**Заморозить свёрточную часть.** Признаки букв у готовой модели хорошие; портит
их дообучение на узком наборе. Учить оставили только чтение последовательности.
Строки целиком: 24 % → 66 %.

**Добавить строчные буквы.** На чертеже почти всё написано прописными, и модель
переставала узнавать нижний регистр: слово «уплотнительными» она выдавала как
«УПЛОТНИТЕЛЫНЫМИ». Единственное место, где строчных много подряд, — примечания
под таблицами. Их и добавили в обучение. Строки целиком: 66 % → 86 %.

## Что осталось

Оставшиеся ошибки — не чтение, а неразличимые пары:

```
эталон: Канализация дождевая К3      модель: Канализация дождевая КЗ
эталон: Канализация дождевая К1      модель: Канализация дождевая K1
эталон: Водопровод хозяйственно-питьевой В2   модель: ... 82
```

Кириллическая «К» и латинская «K», «З» и «3», «В» и «8» в этом шрифте рисуются
одинаково. Никакая модель их не различит, потому что различия нет — его даёт
только формат колонки: в номере сети после буквы идёт цифра, в марке колодца
после букв дефис и число. Такие правки делаются после распознавания, и в этом
замере они намеренно не применялись: иначе цифры показывали бы работу
исправлений, а не чтения.

## Данные

Чертежи заказчиков в этот репозиторий не попадают ни строкой. Всё синтетическое:

- **Шрифт** — [osifont](https://github.com/hikikomori82/osifont), свободная
  реализация ГОСТ 2.304 (GPLv3 с font exception: картинки, сделанные шрифтом,
  под лицензию не подпадают). Скачивается скриптом, в репозитории не лежит.
- **Подписи** — собираются по шаблонам записи из ГОСТ и ТУ производителей:
  трубы, муфты, марки колодцев, отметки, уклоны, примечания.
- **Разбиение** — по шаблонам, а не по строкам. Тестовые шаблоны («муфта»,
  «сеть», «уклон», «высота с плюсом», «скобы») в обучении не участвуют совсем.
  Иначе замер показывал бы память, а не чтение.
- **Порча картинки** — лесенкой, четыре уровня: вектор, хороший растр, обычный
  скан, плохой скан. Размытие, шум, наклон в доли градуса, выцветание штрихов.

## Полная таблица

| Уровень | Что это | Готовая | Дообученная |
|---|---|---|---|
| 0 | вектор, чистая вырезка | 86,1 % / 58,8 % | 98,7 % / 86,2 % |
| 1 | хороший растр | 87,9 % / 62,5 % | 99,6 % / 90,0 % |
| 2 | обычный скан | 88,9 % / 58,8 % | 99,6 % / 86,2 % |
| 3 | плохой скан | 88,8 % / 56,2 % | 99,5 % / 83,8 % |

Две цифры в ячейке: доля верных символов и доля строк, совпавших до знака.

Готовая модель почти не проседает от уровня к уровню — значит, спотыкается она
не о шум, а о сам шрифт.

## Повторить

```
pip install -r requirements.txt
python fetch_font.py                 # скачивает osifont
python measure.py 80                 # готовая модель
python train.py --epochs 3 --rows 8000 --lr 1e-4 --freeze --out cad.pth
python measure.py 80 cad.pth         # дообученная
python measure.py 80 cad.pth --errors
```

Обучение идёт на ноутбуке: три эпохи по 8000 подписей — около минуты на Apple
MPS, без аренды GPU.
